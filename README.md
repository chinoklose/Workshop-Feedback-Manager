# Workshop Feedback Manager

A Python project demonstrating **string manipulation**, **file I/O**, and **robust exception handling** using workshop participant feedback data.

Created for **CS1101-01 Programming Fundamentals** (Unit 7).

---

## 📂 Project Structure

| File | Description |
| :--- | :--- |
| [`q1.py`](q1.py) | **String Processing**: Trimming outer whitespace, standardizing keywords (`speaker` → `presenter`), normalizing internal spaces, and applying title-casing. |
| [`q2.py`](q2.py) | **File I/O Operations**: Writing feedback lists to file, reading lines sequentially, and appending new feedback to `feedback.txt`. |
| [`q3.py`](q3.py) | **Exception Handling**: Safe file reading handling `FileNotFoundError` and `PermissionError` with clean `finally` teardown. |
| [`q4.py`](q4.py) | **Data Analysis & Summary Report**: Parsing feedback lines, counting total entries and keyword occurrences (`great`), and writing metrics to `summary.txt`. |
| `feedback.txt` | Stored workshop participant feedback entries. |
| `summary.txt` | Formatted summary report generated by `q4.py`. |

---

## 🚀 Getting Started

### Prerequisites
- Python 3.x

### Running the Scripts
Run any part directly with Python:

```bash
# Question 1: String cleaning demo
python3 q1.py

# Question 2: Write, read, and append feedback
python3 q2.py

# Question 3: Exception handling demo
python3 q3.py

# Question 4: Generate summary report
python3 q4.py
```
